# EPIC-002: Blueprint Workspace — User Stories

## 역할 정의

| 역할 | 설명 |
|---|---|
| 출제 관리자 | Blueprint를 설계하고 관리하는 사용자 (contents-manager 로그인 사용자) |

---

## Story 1: Blueprint 목록 관리

**배경:**
출제 관리자는 여러 평가 기준(Blueprint)을 독립적으로 운영할 수 있어야 한다. Blueprint는 과목(Subject)과 독립적으로 존재하며, 이후 문항 생성 시 선택해 연결한다.

### US-1.1: Blueprint 생성
```
출제 관리자로서,
이름과 설명을 입력해 새 Blueprint를 생성하고 싶다.
이로써 평가 기준별 독립된 설계 공간을 가질 수 있다.
```

**인수 조건:**
- "Blueprint 워크스페이스" 탭에서 "+ 새 Blueprint" 버튼을 누르면 생성 폼이 나타난다
- 이름(필수) + 설명(선택) 입력 후 저장하면 고유 Blueprint_ID가 부여된다
- 생성 직후 해당 Blueprint의 편집 화면으로 이동한다

### US-1.2: Blueprint 목록 조회
```
출제 관리자로서,
기존 Blueprint 목록을 보고 원하는 것을 선택하고 싶다.
이로써 여러 평가 기준을 전환하며 관리할 수 있다.
```

**인수 조건:**
- 탭 진입 시 Blueprint 목록(이름, 생성일, 상태)이 표시된다
- 목록에서 Blueprint를 클릭하면 해당 Blueprint의 편집 화면으로 전환된다
- Blueprint가 없으면 빈 상태 안내 메시지와 생성 버튼이 표시된다

### US-1.3: Blueprint 삭제
```
출제 관리자로서,
불필요한 Blueprint를 삭제하고 싶다.
이로써 목록을 깔끔하게 유지할 수 있다.
```

**인수 조건:**
- 삭제 확인 다이얼로그가 표시된다
- 삭제된 Blueprint는 soft delete 처리되어 참조 무결성이 보호된다
- (추후 EPIC-003 연동 시) 문항이 참조 중인 Blueprint는 삭제가 차단되거나 경고가 표시된다

## Story 2: 인지 성숙도 매트릭스 설정

**배경:**
각 내용 레이어(Seed, Concept, TechStack)는 서로 다른 인지 단계를 가진다. 출제 관리자는 이 단계들을 도메인 특성에 맞게 커스터마이징할 수 있어야 한다.

### US-2.1: 레이어별 인지 단계 조회
```
출제 관리자로서,
Blueprint의 레이어별 인지 단계 목록을 격자로 보고 싶다.
이로써 현재 설계된 매트릭스 전체를 한눈에 파악할 수 있다.
```

**인수 조건:**
- 행: 내용 레이어 (Seed / Concept / TechStack)
- 열: 해당 레이어의 인지 단계 목록
- 각 셀에는 단계 이름이 표시된다
- 기본값으로 PRD 명시된 단계가 미리 채워진다 (Seed: 인식·리스크·통제, Concept: 원리·매핑·대안, Tech: 스펙·디버깅·전환)

### US-2.2: 인지 단계 이름 수정
```
출제 관리자로서,
특정 레이어의 인지 단계 이름을 직접 수정하고 싶다.
이로써 도메인에 맞는 용어로 매트릭스를 맞춤화할 수 있다.
```

**인수 조건:**
- 셀 클릭으로 인라인 편집 모드 진입
- 편집 후 Enter 또는 포커스 이탈 시 자동 저장
- 빈 이름으로는 저장할 수 없다

### US-2.3: 인지 단계 추가
```
출제 관리자로서,
특정 레이어에 새 인지 단계를 추가하고 싶다.
이로써 도메인 특성에 맞게 평가 축을 확장할 수 있다.
```

**인수 조건:**
- 각 레이어 행 끝에 "+ 단계 추가" 버튼이 있다
- 추가 시 빈 인라인 입력 셀이 생긴다
- 저장하면 해당 레이어의 마지막 순서로 추가된다

### US-2.4: 인지 단계 삭제
```
출제 관리자로서,
필요 없는 인지 단계를 삭제하고 싶다.
이로써 매트릭스를 간결하게 유지할 수 있다.
```

**인수 조건:**
- 셀 hover 시 삭제(×) 버튼이 나타난다
- 레이어당 최소 1개의 단계는 유지되어야 한다 (0개 삭제 차단)

## Story 3: 통합 항목(Z-Axis) 관리

**배경:**
단일 노드·단계 조합이 아닌, 여러 레이어와 인지 단계를 아우르는 복합 문항 출제 기준이 필요하다. 이를 "통합 항목"이라 부르며 Blueprint에 종속된다.

### US-3.1: 통합 항목 생성
```
출제 관리자로서,
복수 레이어·단계 조합을 지정해 통합 항목을 추가하고 싶다.
이로써 시니어 레벨 종합 문항의 출제 기준을 정형화할 수 있다.
```

**인수 조건:**
- 이름 입력 + 매트릭스에서 조합(레이어 × 단계) 멀티 셀렉트
- 조합은 최소 2개 이상 선택해야 저장 가능
- 저장 시 통합 항목이 Blueprint의 Z-Axis 목록에 추가된다

### US-3.2: 통합 항목 목록 조회
```
출제 관리자로서,
Blueprint에 정의된 통합 항목 목록을 보고 싶다.
이로써 어떤 복합 출제 기준이 설계되어 있는지 파악할 수 있다.
```

**인수 조건:**
- 각 통합 항목의 이름과 포함된 조합 목록(태그 형태)이 표시된다
- Blueprint 편집 화면 하단 또는 별도 섹션에 배치된다

### US-3.3: 통합 항목 삭제
```
출제 관리자로서,
통합 항목을 삭제하고 싶다.
이로써 설계를 정리할 수 있다.
```

**인수 조건:**
- 확인 없이 즉시 삭제 (항목 자체가 실험적이므로 빠른 편집 우선)
- 삭제된 통합 항목은 Blueprint에서 즉시 사라진다
